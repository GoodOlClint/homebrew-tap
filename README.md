# GoodOlClint Tap

## How do I install these formulae?

`brew install goodolclint/tap/<formula>`

Or `brew tap goodolclint/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "goodolclint/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
